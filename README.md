# Better Days

Rate each day across three pillars (Physical, Emotional and Financial), plan tomorrow and review your to-dos.

**Install:** open **https://lancematheson.github.io/Better-days/** on your iPhone in Safari, then tap
**Share → Add to Home Screen**. On Android, use Chrome's menu → **Add to Home screen**.

Everything you enter is saved only on your phone. Tips need an internet connection; everything else works offline.

For development notes see `CLAUDE.md`; for the full feature spec see `docs/spec.md`.
